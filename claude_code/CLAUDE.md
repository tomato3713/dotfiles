### PR作成

#### title 記入時の注意点

- 50文字前後で何を修正・実装したのかを表わすこと

#### Description 記入時の注意点

- 変更内容を把握するために必要な前提知識があれば記載すること
- 同じ説明を繰り返さないこと
- やったことの記述について
  - PRの中心的な内容である場合を除いて、formatter実行など当然のことは書かない
  - コードに表現される詳細は書かない。PRの変更によって何が実現されるのかを書く
- 動作確認の記述について
  - CIで検証されることは指示がない限り書かない。
  - もし機能フラグの有無で切り替えがあれば、機能フラグ名を記載すること。
  - もし時限切り替えがあれば、その時刻、URLを記載すること
